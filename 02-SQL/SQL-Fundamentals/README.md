# SQL Fundamentals

## Overview

This project demonstrates fundamental SQL concepts completed as part of my HyperionDev Cyber Security Bootcamp.

The exercises focus on creating and managing a relational database using SQL. The project covers the complete lifecycle of database management, including creating tables, inserting records, querying data, updating records, deleting records, and removing database objects.

---

## Features

- Create database tables
- Insert multiple records
- Retrieve data using SELECT statements
- Filter query results using WHERE clauses
- Update existing records
- Delete records from a table
- Drop database tables

---

## How to Use

Open the SQL script in your preferred SQL editor or database management system and execute the statements in order.

The script demonstrates:

1. Creating a Student table
2. Inserting sample records
3. Retrieving filtered data
4. Updating existing records
5. Deleting records
6. Modifying existing data
7. Dropping the table
