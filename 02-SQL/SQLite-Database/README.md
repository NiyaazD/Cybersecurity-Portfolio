# SQLite Database

## Overview

SQLite Database is a Python application developed as part of my HyperionDev Cyber Security Bootcamp.

The project demonstrates how Python interacts with a SQLite database to perform common database operations. It creates a database and table, inserts records, retrieves data, updates existing records, deletes records, and displays the final dataset.

---

## Features

- Create a SQLite database
- Create a table using SQL
- Insert multiple student records
- Query records using SQL
- Update existing records
- Delete records
- Display database contents
- Commit database transactions

---

## Technologies Used

- Python 3
- SQLite
- sqlite3 module

- SQLite database management

- Data retrieval
- Database updates

## How to Run

1. Ensure Python 3 is installed.
2. Navigate to the project folder.
3. Run:

```bash
python database_manip.py
```

The application will automatically create the SQLite database if it does not already exist.
