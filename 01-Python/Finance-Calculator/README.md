# Finance Calculator

## Overview

The Finance Calculator is a Python command-line application developed as part of my Hyperion Development Cyber Security Bootcamp.

The application allows users to calculate either:

* Investment returns using **simple** or **compound interest**
* Monthly repayments on a home loan (bond)

This project demonstrates the use of Python programming fundamentals to solve real-world financial calculations.

---

## Features

* Calculate investment returns using simple interest
* Calculate investment returns using compound interest
* Calculate monthly bond repayments
* Accepts user input from the command line
* Displays formatted financial results

## How to Run

1. Ensure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run the application:

```bash
python finance_calculator.py
```
