# Password Hashing

## Overview

Password Hashing is a Python command-line application developed as part of my HyperionDev Cyber Security Bootcamp.

The application demonstrates secure password hashing using the bcrypt library. It accepts a user-provided password, generates a unique random salt, and produces a secure hashed password suitable for storage.

---

## Features

- Accepts a password from the user
- Uses the bcrypt library for secure hashing
- Generates a random salt automatically
- Produces a unique hash for each password
- Demonstrates password security best practices
