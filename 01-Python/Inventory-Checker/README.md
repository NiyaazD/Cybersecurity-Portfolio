# Inventory Checker

## Overview

Inventory Checker is a Python command-line application developed as part of my HyperionDev Cyber Security Bootcamp.

The application manages shoe inventory records stored in a text file. Users can view inventory, add new shoes, search products, determine the highest and lowest stock levels, calculate inventory value, and identify products for sale.

---

## Features

- Load inventory from a text file
- View all shoe records
- Add new inventory items
- Search for shoes by product code
- Display the shoe with the highest quantity
- Display the shoe with the lowest quantity
- Calculate the total value of each inventory item
- Display inventory in a formatted table
