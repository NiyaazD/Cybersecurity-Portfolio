# Task Manager

## Overview

Task Manager is a Python command-line application developed as part of my HyperionDev Cyber Security Bootcamp.

The application allows users to log in, manage tasks, register new users and display task statistics. Task information and user credentials are stored in text files, providing practical experience with persistent data storage.

---

## Features

- User login and authentication
- Register new users
- Add new tasks
- View all tasks
- View tasks assigned to the logged-in user
- Display task and user statistics (administrator only)
- Store user and task data using text files

## How to Run

1. Ensure Python 3 is installed.
2. Open a terminal or command prompt.
3. Navigate to the project folder.
4. Run:

```bash
python task_manager.py
```
