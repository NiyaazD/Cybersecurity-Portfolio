# Cipher Encoder

## Overview

Cipher Encoder is a Python command-line application developed as part of my HyperionDev Cyber Security Bootcamp.

The application encodes messages using a Caesar Cipher with a shift value of 15. It preserves uppercase and lowercase letters while leaving numbers, spaces, and punctuation unchanged.

---

## Features

- Encode text using a Caesar Cipher
- Supports uppercase and lowercase letters
- Preserves spaces, numbers and punctuation
- Uses ASCII values with `ord()` and `chr()`
- Wraps around the alphabet using modulo arithmetic
