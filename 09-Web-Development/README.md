# Web Development

## Overview

This section of the cybersecurity portfolio contains practical web development work completed as part of the coursework.

The projects demonstrate experience with HTML, semantic HTML, CSS, page structure, tables, and the use of images within web pages.

---

## HTML

The `HTML` directory contains practical HTML exercises, including:

- `index.html` — HTML page development
- `tables.html` — creating and working with HTML tables

These exercises demonstrate the use of HTML elements to structure and present web content.

---

## Semantic HTML

The `Semantic-HTML` directory contains a practical webpage demonstrating the use of semantic HTML elements.

The project includes:

- `rugby.html` — semantic HTML webpage
- `Pieter-Steph.jpg` — supporting image used by the webpage

The project demonstrates the organisation of webpage content using meaningful semantic elements and the integration of images.

## CSS
