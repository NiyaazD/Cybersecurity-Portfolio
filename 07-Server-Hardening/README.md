# Server Hardening

## Overview

This project documents practical server hardening activities performed on an Apache web server running in a Windows environment.

The assessment focused on configuring and testing Apache, enabling HTTPS, and verifying the SSL/TLS certificate used by the local web server.

The work demonstrates practical experience with web server configuration, HTTPS setup, certificate inspection, and security verification.

---

## Objectives

The main objectives of this assessment were to:

- Configure and test an Apache web server.
- Verify that the Apache web server was accessible locally.
- Configure HTTPS for the Apache server.
- Generate and configure an SSL/TLS certificate.
- Verify the certificate details.
- Confirm that HTTPS was successfully enabled.
- Document the configuration and testing performed.
