# Incident Response

## Overview

This section of the cybersecurity portfolio contains practical work relating to incident response and the development of an incident response plan.

The project demonstrates the structured approach used to prepare for, respond to, contain, and recover from cybersecurity incidents.

---

## Incident Response Plan

The `incident_plan.pdf` document contains the completed Incident Response Plan.

The plan demonstrates the application of incident response principles to a simulated cybersecurity incident and documents the actions and processes required throughout the incident lifecycle.

---

## Incident Response Lifecycle

The work covers the key stages of incident response:

- Preparation
- Detection and analysis
- Containment
- Eradication
- Recovery
- Lessons learned

---

## Skills Demonstrated

This work provided practical experience with:

- Incident identification and analysis
- Incident response planning
- Incident containment
- Eradication and recovery procedures
- Security incident documentation
- Post-incident review
- Applying structured incident response processes
