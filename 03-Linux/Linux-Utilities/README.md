# Linux Utilities (Python)

## Overview

This project contains Python implementations of several common Linux command-line utilities. It was completed as part of my HyperionDev Cyber Security Bootcamp to demonstrate an understanding of how fundamental Linux commands work internally.

Rather than relying on the operating system's built-in commands, these programs recreate similar functionality using Python.

---

## Utilities Included

### cat.py
Displays the contents of a file to the terminal, similar to the Linux `cat` command.

### echo.py
Prints user-provided text to the terminal, replicating the behaviour of the Linux `echo` command.

### grep.py
Searches a text file for matching strings and displays lines containing the specified search term, similar to the Linux `grep` command.
